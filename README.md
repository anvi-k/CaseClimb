# CaseClimb

CaseClimb is a synthetic virtual patient encounter prototype for healthcare students: a faculty authoring Studio, ten-minute patient conversations, progressively disclosed charts, and evidence-linked formative feedback.

The [workshop app](https://tvgsy5zqad.execute-api.us-west-2.amazonaws.com/web/) is deployed on AWS in `us-west-2` and requires the host's shared entrance password. This temporary workshop deployment has no confirmed long-term hosting expiry. Eight imported synthetic patients are private, unreviewed drafts; faculty review and publication are required before practice.

The local source now uses one **Patient cases** library. In **Patient Studio**, choose **+ New case** to start from a clinical history template or a communication template for Alex, Maya, Jordan, or Evelyn. Communication templates include authored patient facts, learning objectives, illustrations, and stock voices; they become ordinary editable drafts and need faculty review and publication before students can launch them. All published cases use the same student access, ten-minute encounter, chart, and evidence-linked feedback workflow. Voice and typed interaction are available in that encounter flow. Standalone practice-chat launch is retired; existing conversation records remain readable. This change has been verified locally and has not been deployed to the workshop app.
When streaming is configured, ElevenLabs Scribe supplies live transcription and reply audio streams through the AWS WebSocket backend. Spoken controls require explicit consent; typed questions and captions remain available. See the [streaming contract and setup](research/streaming-backend.md).


Start with the [research index](research/README.md). It includes the October 10 meeting notes, a timestamped recording transcript, challenge requirements, clinical education evidence, and voice/avatar integration options.

The first slice is an emergency-department communication/history encounter. Faculty author and review a case before publishing an immutable version. Student answers come from the authored case; unknown findings remain unknown. Patient mood and simulated rapport are separate from educational assessment.

Run locally with `uv sync`, independently generated `CASECLIMB_ADMIN_TOKEN` and `CASECLIMB_STUDENT_CODE`, and `uv run uvicorn backend.app:app --host 127.0.0.1 --port 8015`. Open `http://127.0.0.1:8015/web/`. See the [backend contract](backend/README.md), [AWS deployment runbook](infra/README.md), and [delivery/verification record](research/implementation-and-verification-2026-10-10.md).

ElevenLabs supplies speech with per-case voice and delivery controls. The deployed live preview sends its audio to the free LiveAvatar Wayne sandbox for responsive video. The sandbox shares one rendered face across profiles and ends after at most one minute; the ten-minute encounter continues with voice, illustrations, and captions. Actual Chrome video rendering and a typed question with synchronized voice were verified. Physical microphone acceptance remains a hands-on check. A separate ElevenLabs-generated introduction is prerecorded; native video generation is asynchronous and its API requires Pro or above. No Pro upgrade was performed.

AWS deployment includes a shared entrance password with a signed, revocable four-hour session. Faculty tokens and encounter access remain separate. The deploy script saves access values in ignored `.private/app-access.md`; no credentials or raw sponsor materials are committed. Imported patient sources stay private drafts until a qualified faculty reviewer supplies reveal rules and reviews them. No real patient data, institutional identity integration, clinical validation, or validated grades are established by this prototype.

The deployed AWS setup also includes a six-widget CloudWatch dashboard, four error/throttle alarms, and seven-day DynamoDB point-in-time recovery. Alarm notifications are disabled. The [setup runbook](infra/README.md) covers reproducing the deployment, private configuration, monitoring, recovery, and workshop expiry. GitHub Actions runs backend, browser-controller, and infrastructure checks without cloud credentials.
