# CaseClimb

Research and planning for a reusable virtual patient encounter for healthcare students.

Start with the [research index](research/README.md). It includes the October 10 meeting notes, a timestamped recording transcript, challenge requirements, clinical education evidence, and voice/avatar integration options.

The proposed first slice is a ten-minute, faculty-reviewed encounter in the emergency department. These documents describe research and proposed work; this repository does not yet contain an application.
